# MeepleHub

Plateforme de gestion de collection de jeux de société.

Fonctionnalités :

- Gestion de collection
- Prêt de jeux
- Vente de jeux
- Échange entre utilisateurs
- Recherche multicritères
- Gestion des états des jeux
- Historique des transactions

Technologies :

- ASP.NET Core
- Entity Framework Core
- SQL Server
- React
- Typescript
- Clean Architecture
